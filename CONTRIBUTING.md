# Contributing to MOESALAAT Desktop

First off, thank you for considering contributing to **MOESALAAT Desktop**! It's people like you that make open source such a great community to learn, inspire, and create.

## How Can I Contribute?

### Reporting Bugs

This section guides you through submitting a bug report. Following these guidelines helps maintainers and the community understand your report, reproduce the behavior, and find related reports.

1. **Check if the bug has already been reported.** Search the [issue tracker](https://github.com/musahabibulloh/moesalaat/issues) to see if someone else has already reported the issue.
2. **Use the Bug Report template.** If no one has reported it, open a new issue and use the provided Bug Report template. Include as much detail as possible.

### Suggesting Enhancements

Enhancement suggestions are tracked as GitHub issues. 

1. **Check if the enhancement has already been requested.** Search the [issue tracker](https://github.com/musahabibulloh/moesalaat/issues).
2. **Use the Feature Request template.** Open a new issue and provide a clear and descriptive title and a detailed description of the proposed feature.

### Your First Code Contribution

Unsure where to begin contributing? You can start by looking through these `good first issue` and `help wanted` issues:

*   [Good First Issues](https://github.com/musahabibulloh/moesalaat/issues?q=is%3Aissue+is%3Aopen+label%3A%22good+first+issue%22) - Issues that should only require a few lines of code, and a test or two.
*   [Help Wanted](https://github.com/musahabibulloh/moesalaat/issues?q=is%3Aissue+is%3Aopen+label%3A%22help+wanted%22) - Issues that are a bit more involved than `good first issue` but still good for learning the codebase.

### Pull Requests

1. **Fork the repo** and create your branch from `main`.
2. **Write tests** if your change adds new functionality.
3. **Ensure the test suite passes.**
4. **Format your code.** Make sure your code follows the style guidelines of the project.
5. **Issue that PR!** Link any relevant issues in the PR description.

## Setting Up the Development Environment

1. Fork the repository
2. Clone your fork: `git clone https://github.com/YOUR_USERNAME/moesalaat.git`
3. Navigate to the project directory: `cd moesalaat`
4. Install dependencies: `npm install` (or `yarn install` / `pnpm install`)
5. Start the development server: `npm run tauri dev`
6. Build the final application: `npm run tauri build`
